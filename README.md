# 📄 Meu Currículo — Arthur Serapião Beraldo

Currículo pessoal desenvolvido como página web, hospedado via **GitHub Pages**. O projeto faz parte da disciplina **Tecnologias de Desenvolvimento para Internet III** do curso de Bacharelado em Sistemas de Informação do IFSULDEMINAS — Campus Machado.

> 🔗 **Acesse online:** [arthur-serapiao.github.io/meu-cv](https://anfitras.github.io/meu-cv)

---

## 📌 Sobre o Projeto

O objetivo é construir uma página web que funcione como currículo profissional, demonstrando ao mesmo tempo as habilidades de desenvolvimento front-end do autor. O layout, a identidade visual e a experiência do usuário ficam inteiramente a critério do desenvolvedor.

O site apresenta:

- **Informações de contato** e perfis profissionais (LinkedIn e GitHub)
- **Resumo profissional** com objetivos de carreira
- **Formação acadêmica** com instituições e períodos
- **Projetos acadêmicos** e experiências relevantes
- **Habilidades técnicas** organizadas por categoria
- **Idiomas** com certificação
- **Palestras e eventos** de tecnologia participados

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Uso |
|---|---|
| **HTML5** | Estrutura semântica da página (`header`, `main`, `aside`, `footer`, `section`, `nav`) |
| **CSS3** | Estilização completa, layout com Flexbox e Grid, animações e responsividade |
| **JavaScript (ES6+)** | Scroll reveal animado e navegação suave por âncoras |
| **Google Fonts (Inter)** | Tipografia carregada via CDN |
| **Git** | Controle de versão do projeto |
| **GitHub** | Hospedagem do repositório remoto |
| **GitHub Pages** | Deploy e hospedagem pública da página |

> O projeto foi desenvolvido **sem frameworks, bibliotecas externas ou dependências de terceiros** — apenas HTML, CSS e JS puros, conforme exigido pela atividade.

---

## 🎨 Destaques do Design

- **Tema escuro** com fundo `#030303` e paleta ciano/roxo
- **Glassmorphism** nos cards e na navbar (blur + bordas translúcidas)
- **Navbar flutuante** centralizada com efeito de vidro (`backdrop-filter: blur`)
- **Efeitos de glow** animados no fundo (orbes com `filter: blur` em loop)
- **Foto estilo polaroid** com rotação e hover interativo
- **Scroll reveal** nas seções principais (animação de entrada ao rolar a página)
- **Hover interativo** em cards, tags de habilidades e links sociais
- **Layout responsivo** — reorganiza para coluna única em telas menores que 900px
